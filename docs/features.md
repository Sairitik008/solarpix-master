# SolarPix Feature Roadmap

## Core Features
1. **Secure Encrypted Media Vault:** Private photo vault with AES-256 SQLCipher metadata protection.
2. **Interactive Photo Gallery:** Grid view, full-screen viewer, zooming, sorting, and tag filtering.
3. **Solar Sync & Storage Services:** Centralized data access layer for seamless local file indexing.
4. **Custom Theme Engine:** Radiant dark theme optimized for OLED screens.
