# SolarPix Design Document

## Design Principles
- **Vibrant & Modern Aesthetic:** Dark mode primary with solar-themed accent gradients (warm amber, radiant yellow, deep cyan).
- **Smooth Micro-animations:** High responsiveness and intuitive transitions for photo gallery interactions.
- **Privacy & Security First:** End-to-end encrypted storage for local image metadata and vault data.

## Typography & Theme System
- Font Family: System Default / Inter (Clean Sans-Serif)
- Primary Color: `#FF9500` (Solar Amber)
- Accent Color: `#FF5E00` (Solar Flare)
- Dark Background: `#0D0D11` (Deep Space Dark)
- Card Background: `#1A1A22` (Elevated Surface)
- Text Primary: `#FFFFFF`
- Text Secondary: `#A0A0B0`
